# WineBox

**Winlator + UI stile GameHub**

WineBox prende la potenza di [Winlator](https://github.com/brunodev85/winlator) (Wine + Box64 su Android) e la combina con un'interfaccia moderna stile GameHub.

---

## Obiettivo

Un unico APK bello e semplice per:

- Far girare applicazioni Windows (x86_64) sul telefono
- Interfaccia hub moderna (griglia, card, tema scuro)
- Esperienza più pulita e intuitiva rispetto a Winlator classico
